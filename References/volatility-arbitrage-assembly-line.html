The five sheets

THE PROBLEM
Traditional pricing models like Black-Scholes are too slow and inflexible when you need prices for hundreds of option contracts at once.
THE SOLUTION
Borrow the Fast Fourier Transform from signal processing to compute a whole grid of theoretical option prices in one pass, instead of one contract at a time.
IN
Spot price, risk-free rate, time to maturity, a characteristic function
OUT
A grid of theoretically "perfect" option prices
I use Carr–Madan's FFT to establish an algorithmic, mathematically perfect ground-truth baseline before any machine learning touches the data. — the one-sentence answer, if asked
THE PROBLEM
Real market data is messy, sparse, and noisy — wide bid-ask spreads confuse traditional statistical methods.
THE SOLUTION
Treat the volatility surface as a 2D image and run it through a convolutional neural network, so the model can smooth noise and pick out spatial anomalies the way it would spot a flaw in a picture.
IN
The noisy, real-world volatility grid (strike vs. expiry)
OUT
A smoothed surface, plus the exact coordinates where mispricings sit
Instead of standard time-series analysis, this paper taught me to treat the volatility surface as a 2D image, using spatial pattern recognition to detect pricing anomalies. — the one-sentence answer, if asked
THE PROBLEM
A full volatility surface is hundreds of data points. Feed that raw into a generative model and it's expensive to train and prone to breaking.
THE SOLUTION
A variational autoencoder squashes the whole 3D surface down into a small, dense "latent vector" — a compact summary of the market's current mood.
IN
The massive, raw 3D volatility surface
OUT
A compressed 1D vector representing the current "market regime" (e.g. high fear, low fear)
I use Hull's VAE for dimensionality reduction — it compresses the massive data grid into a lightweight "market regime" vector so the generative model downstream can run efficiently. — the one-sentence answer, if asked
THE PROBLEM
Ordinary GANs are great at faces, terrible at finance — left unconstrained, a generator will invent prices that allow arbitrage, i.e. impossible free money.
THE SOLUTION
A conditional GAN with a custom penalty: any generated market scenario that permits arbitrage gets punished during training, so the network learns to only output physically valid markets.
IN
Random noise + the compressed market-regime vector from Sheet 3
OUT
10,000 synthetic, fake-but-realistic future volatility surfaces that obey no-arbitrage constraints
This is the base paper. It proves generative AI can create mathematically valid synthetic market data, which I use to generate 10,000 future scenarios to stress-test each trade. — the one-sentence answer, if asked
THE PROBLEM
Deep learning outputs raw tensors and probabilities. A portfolio manager can't read a tensor — the model is a black box.
THE SOLUTION
A multi-agent LLM framework where specialized agents read the quantitative output and reason over it in writing, turning numbers into a plain-English case.
IN
The raw math — CNN anomaly coordinates, VolGAN survival probabilities
OUT
A plain-English paragraph explaining why a trade should (or shouldn't) be made
I use this paper's multi-agent framework for explainable AI — it translates the black-box tensor outputs of the GAN into a transparent trading rationale. — the one-sentence answer, if asked

Sheet 6 — connecting the dots

If the professor asks "how do all these papers fit into one project?" — this is the walkthrough.

  1. The setup
    Pull real options data and run it through Carr–Madan (Sheet 1) to find out what the price should be in a perfect world.
  2. The discovery
    Hand that data to the CNN (Sheet 2). It compares the real world to the perfect math and flags the exact coordinate where a mispricing exists.
  3. The compression
    Before testing that mispricing, summarize the whole market. The VAE (Sheet 3) compresses it into a tiny "regime" state.
  4. The stress test
    No trading yet. Feed the compressed regime into VolGAN (Sheet 4): "generate 10,000 possible futures based on this regime," then simulate the trade across all of them to see if it survives.
  5. The final output
    Pass the VolGAN survival rate and the CNN coordinates to the FinRobot LLM (Sheet 5), which writes out the case in plain English.
> CNN found an anomaly. VolGAN confirms 85% survival rate across 10,000 futures. ACTION: EXECUTE TRADE.
