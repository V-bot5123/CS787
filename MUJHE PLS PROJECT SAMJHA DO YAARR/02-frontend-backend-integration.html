The bridge architecture

Async RESTful API (FastAPI/Flask). Backend loads PyTorch tensors and runs the heavy compute. Python exposes endpoints like POST /api/run_generative_stress_test. Frontend HTML uses fetch() to call them asynchronously; backend replies with strict JSON, updating the DOM without a page refresh — keeps the UI responsive while the GAN generates 10,000 surfaces in the background.
